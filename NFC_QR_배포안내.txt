광야 어드벤처 NFC·QR 배포 안내

1. 이 웹앱을 휴대폰에서 열려면 index.html 파일 자체가 아니라 인터넷에 공개된 HTTPS 주소가 필요합니다.
   예: https://church-event.example.com/

2. 가장 간단한 배포 방법
   - GitHub Pages, Netlify, Vercel 또는 교회 웹서버에 이 폴더 전체를 업로드합니다.
   - 배포 후 휴대폰에서 주소가 정상적으로 열리는지 확인합니다.

3. QR 코드
   - 배포된 HTTPS 주소를 QR 코드 생성기에 입력합니다.
   - 조별로 바로 인식시키려면 주소 뒤에 ?team=번호를 붙입니다.
     예: https://church-event.example.com/?team=3
     위 QR로 접속하면 3조로 자동 설정됩니다.

4. NFC 태그
   - NFC Tools 같은 앱에서 태그에 URL/URI 레코드를 기록합니다.
   - 기록할 값은 배포된 HTTPS 주소입니다.
   - 조별 NFC 태그도 ?team=번호 주소를 사용할 수 있습니다.

5. 중요
   - 현재 버전은 localStorage/BroadcastChannel 기반이라 서로 다른 휴대폰 간 실시간 동기화가 되지 않습니다.
   - 행사 운영용 실시간 현황·만나 순위를 모든 참가자가 동시에 보려면 Firebase, Supabase 또는 별도 서버 DB 연결이 필요합니다.
   - 관리자 비밀번호도 현재는 프론트 코드에 포함되어 있으므로 실제 운영 전 서버 인증 방식으로 바꾸는 것이 안전합니다.
