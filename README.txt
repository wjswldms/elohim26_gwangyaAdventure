광야 어드벤처 웹앱 v3

1. 압축을 푼 뒤 index.html을 Chrome/Edge/Safari에서 실행하세요.
2. 상시 미션은 참여 조 현황 및 관리자 관리 대상에서 제외했습니다.
3. 관리자 로그인은 광야 어드벤처 타이틀을 1.5초 안에 연속 3회 누른 후 개인 비밀번호를 입력합니다.
4. 이 버전의 실시간 반영은 같은 브라우저/기기의 탭 간 시연용입니다. 여러 휴대폰 간 실시간 동기화는 Firebase/Supabase 등 서버 연동이 필요합니다.

[v6 변경사항]
- 총 13개 조 지원
- 참여 대기 신청 및 조별 최대 2개 대기 제한
- 관리자 참여 조 버튼 선택(1~13조)
- 참여 조 선택 시 해당 조 자동 대기열 제거
- 모바일 퀘스트명 중복 라벨 숨김

[v7 추가 기능]
- 지도 배지에 참여 조 수와 대기 조 수 동시 표시
- 여유/모집 중/진행 중 혼잡도 색상
- 참가자별 예상 대기시간 안내
- 관리자 조별 게임 종료 버튼
- 게임 종료 시 대기열 첫 번째 조 자동 참여 전환
- 관리자 만나 +1/+3/+5/기본 보상 빠른 지급
- 모바일 퀘스트명 중복 버튼 기본 숨김
- 내 조 순위 및 참여 카드 강조


[v8 조별 토큰 접속]
- ?team=숫자 방식은 더 이상 조 인증에 사용하지 않습니다.
- TEAM_TOKEN_URLS.txt에 있는 조별 전용 URL을 QR/NFC에 기록하세요.
- 유효한 token 없이 접속하면 현황 열람만 가능하고 대기 신청/취소는 차단됩니다.
- URL의 team 값을 바꿔도 조가 변경되지 않습니다.

- 지도 배지 대기 조 문구 제거
- 퀘스트 팝업 대기 신청 UI 숨김
- 클릭 영역과 배지를 소폭 우측 상단 이동
